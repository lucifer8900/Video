# 中文语音文本回归夹具

本目录只保存合成的中文文本回归数据，用于离线验证场景白名单、异常输入分类、置信度回退和严重误伤统计。它不是剧情内容，也不会进入 NarrativeCompiler、StreamingAssets 或任何发行构建。

voice-evaluation.dataset.json 固定包含 200 条样本。所有节点、意图和话术均为通用 QA 标识，不含人物、地点、剧情专名、原始录音或 API 密钥。testOnly 与 doNotShip 必须保持为 true。

录音由人工在后续独立补充。录音前必须取得参与者同意，避免说出真实姓名、账号、地址或其他个人信息，并在保存前清除设备元数据。建议本地文件名使用 sample-id.take-number.wav，例如 zh.match.observe.001.01.wav。原始录音、转写缓存和带身份信息的清单不得提交 Git、不得写入日志、不得放入游戏构建；这里只允许未来添加经审核的外部引用或匿名哈希。

本数据集衡量的是合成文本回归基线，不代表生产语音准确率。生产剧情包没有有效 voice intents 时，生产指标必须报告为不可评估，不能用本夹具的通过率替代上线结论。
