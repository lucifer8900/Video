# 《灵脉余烬》原创化命名层

本目录定义游戏生产层使用的稳定名称。运行时、Unity、视频提示词和公开文档只使用 `gameName`、`gameDisplayName`、`gameTerm` 与稳定 ID；不会在每次生成视频或创建 NPC 时重新随机命名。

## 已完成范围

- 110 个角色／生灵，包括两名可操作主角。
- 62 个剧情场景。
- 43 个具名功法、技能、宝物、阵法、丹药、装备和伙伴定义。
- 11 个篇章名、43 个阵营名和 60 个高频地点名。
- 17 张人物图片改用稳定角色 ID 作为文件名；名称变更不再引起二进制资源移动。

名称由项目自建词库和固定种子 `LMYE-20260713-ORIGINALIZE-01` 生成，再按人物身份、地貌和物品功能人工约束。没有从其他小说抽取显著专名。

## 发布隔离

`source-to-game-name-map.json` 含研究源名称和本机来源路径，只为迁移核对使用，标记为 `internalOnly`、`doNotShip`。客户端、视频成片元数据、公开下载包和商店页面不得包含该文件。正式构建应使用显式白名单，只复制运行时 JSON 与批准后的媒体资产。

## 法律与创作边界

改名不会自动消除人物关系、剧情结构、场景构成或视觉设计与来源作品之间的改编关系。若项目走授权改编路线，仍需取得相应权利；若要走完全原创路线，还必须继续实质改写人物关系、事件因果、世界制度和视觉造型，并进行名称、商标与美术相似性审查。

当前 16 张人物板和 18 张场景板仅改了生产名称及文件引用，画面本身尚未因本轮改名而重绘，不能据此宣称视觉已经完成原创化。
