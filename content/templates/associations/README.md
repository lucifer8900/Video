# Association template placeholders

This directory currently contains exactly two CX-402 authoring fixtures. They are
structural placeholders only, carry `approvalStatus: "needs_review"`, and must
never enter the signable association catalog.

The placeholder fallback ID is synthetic and is registered only by tests. It is
not an approved story thread. Production loading therefore remains fail-closed
until human-reviewed templates and pre-authored fallback threads are supplied.
