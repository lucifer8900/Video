- 16:9、1920×1080、24 FPS、10 秒、单条结果，统一 `RM_Film_v01`。
- 七段均为无演员的动态环境母片，不生成旁白、对白、音乐、字幕、按钮、HUD、文字、标志、水印或烧入黑边。
- 摄影机使用固定三脚架或极轻稳定器呼吸；首帧与末帧构图、焦段、曝光和建筑位置尽量一致，使 Unity 可以循环作为对话和选择的动态背景。
- 环境运动必须持续但克制：水、薄雨、雾、灯火、灵脉、叶片、锁链和云层都有物理来源；不能让整幅画面同时闪烁。
- 若平台不能保证无缝循环，最后 2 秒必须回到稳定、中性、无突发动作的构图，Unity 以短交叉淡化循环；不能倒放或插帧制造循环。
- 所有场景共享黑湿玄武岩、氧化青铜、残缺同心环、三道断开的灵脉槽、冷青低亮灵脉、贴地暗赤雾和少量琥珀灯火。绝不是普通山林、乡村药田、通用奇幻地牢或旅游景区。
- 首帧标为“待制作”的场景须先用 Image2 按视觉圣经生成并批准；没有首帧时不要直接反复提交视频，以免世界外观漂移。
