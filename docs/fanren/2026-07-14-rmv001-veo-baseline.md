# RMV-001 Veo 基准镜头交付记录

## 生成规格

- 用途：赤雾秘苑垂直切片开场环境镜头
- 模型：`veo-3.1-lite-generate-preview`
- 输入：秘苑入口视觉目标图 + 英文镜头提示词
- 输出：`rmv_001_gate_dawn.mp4`
- 规格：1280×720、24 fps、8 秒、H.264 视频、AAC 48 kHz 双声道音频
- 文件大小：8,817,938 字节

## 质检结果

- 检查首帧、中帧、尾帧与每秒 2 帧的 16 格接触表。
- 山门、河谷、石阶、营地、赤雾和人物尺度保持连续。
- 未发现明显画面拉伸、横纵比错误、人物肢体突变或建筑跳变。
- 镜头由远景缓慢推进到营地和山门，适合作为世界建立镜头。

## Unity 接入

- 文件位于 `Assets/StreamingAssets/Media/rmv_001_gate_dawn.mp4`。
- `MediaDirector` 将剧情节点 `prologue` 优先映射到该文件。
- 正式文件缺失时仍回退到 `prologue.mp4`，保证切片始终可运行。
- Windows 构建已验证日志包含 `RED_MIST_VIDEO_START cue=prologue`，且实际路径指向 RMV-001 文件。
