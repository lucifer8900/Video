# 《灵脉余烬》战斗与成长系统

日期：2026-07-13  
版本：`0.1-draft`  
项目：`https://github.com/lucifer8900/Video.git`  
配套数据：`content/systems/fanren/combat-taxonomy.json`

## 1. 文档定位与结论

本系统只服务于 `lucifer8900/Video` 的 AI 真人影视互动游戏。《灵脉余烬》是游戏开发代号；本系统把内部研究源中的境界、资质、功法、法宝、丹药、阵法、傀儡、灵兽、灵虫和战斗决策转换成采用新生产名称的 Unity 可执行状态。

核心结论：

1. **不使用“杀怪直接增加人物经验值”。** 修为来自打坐、灵脉、时间、丹药、功法与境界条件；战斗只可能带来材料、情报、传承、人情、伤势和暴露风险。
2. **战斗先比信息与准备，再比境界和底牌。** 侦察、隐匿、克制、阵法、撤退路线、法力余量和神识控制负荷都比连招数量重要。
3. **境界不是单一战力数字。** 同境界内装备、功法和准备可以制造优势；跨大境界通常形成压制，只有正文支持的限制、阵法、特殊宝物、多人协作或逃生方案才能改变结果。
4. **失败推进世界。** 失去战利品、负伤、暴露秘密、错过秘境窗口或宗门评价下降，都可以继续剧情；不能把所有失败都变成读档或死亡。
5. **男女主线使用同一世界规则、不同成长动词。** 沈砚线偏侦察、储备、炼制、藏底牌和撤退；楚明绮线偏功法轮回状态、宗门资源调度、身份隐藏、赤鸾焰环控制和队伍撤离。

## 3. 境界、资质与突破

### 3.1 境界树（`CANON`）

正文第一百二十七章给出三大阶段：

| 大阶段 | 境界 | 游戏中的小境界表达 |
|---|---|---|
| 下境界 | 炼气 | 一至十三层；层内有修为进度与瓶颈 |
| 下境界 | 筑基 | 初期、中期、后期；顶峰可称“假丹”状态，但不是独立大境界 |
| 下境界 | 结丹 | 初期、中期、后期、大成/顶峰；拥有丹火并可长期培炼本命法宝 |
| 下境界 | 元婴 | 初期、中期、后期、大成/顶峰；元婴与神魂成为独立风险对象 |
| 下境界 | 化神 | 初期、中期、后期、大成；尘寰界受天地元气与界面条件限制 |
| 中境界 | 炼虚 | 初期、中期、后期；突破关键涉及“五行合一” |
| 中境界 | 合体 | 初期、中期、后期、大成 |
| 中境界 | 大乘 | 初期至后期的层级进展；持续面对大天劫 |
| 上境界 | 渡劫 | 飞升关口，不做可无限刷取的普通等级 |

`ADAPTATION-BRIDGE`：Unity 将“初/中/后/顶峰”和连续修为沉淀分开保存。`realmStage` 决定规则权限，`cultivationAccumulation` 只表示本阶段积累，积累满并不保证突破。

### 3.2 灵根与资质（`CANON`）

- 五行：金、木、水、火、土。
- 伪灵根：四或五种属性混杂，通常修炼慢、资源成本高。
- 真灵根：两或三种属性，修炼较快。
- 天灵根/天根：单一属性，正文说明修炼速度显著较快，并免去筑基顶峰到结丹的通常瓶颈。
- 变异灵根：两三种五行属性异变升华；正文举雷、冰、暗、风灵根。
- 七曜灵陆补充：丹灵根、器灵根可补足属性，但有适用条件、效率和危险，不是角色创建时的免费选项。

`GAME-ORIGINAL` 数值规则：灵根主要修正**修炼时间、功法兼容、突破准备和资源转化效率**，不直接作为“稀有资质=固定伤害加成”。沈砚的长期强大不能被简化为四灵根角色初始面板异常高。

### 3.3 寿元、天劫与世界时钟

- `CANON`：筑基约可活二百余年，结丹有望四五百年，元婴可达千年量级；具体寿元受伤势、功法和个体影响，不做绝对倒计时。
- `CANON`：七曜灵陆元婴、化神面对约三百年一次的小天劫；炼虚、合体、大乘面对约三千年一次的大天劫；后续天劫更强。
- `ADAPTATION-BRIDGE`：闭关、炼器、养剑、赶路、养虫、疗伤都会推进同一个 `WorldClock`。剧情人物会老去，任务会过期，宗门战争不会为玩家暂停。
- `GAME-ORIGINAL`：界面只显示“寿元充裕/受损/紧迫”和下一次劫期区间，不显示伪精确到天的死亡时间，除非剧情已经明确。

### 3.4 突破不是经验条结算

一次突破检查由以下条件组成：

```text
功法层级达到要求
+ 本阶段修为沉淀达到门槛
+ 灵根/属性路线兼容
+ 身体、经脉、神魂状态允许
+ 丹药、灵物、阵地或天地条件
+ 心境稳定与未解决心魔
+ 寿元/天劫窗口
+ 受控随机结果
```

正文支持的代表门槛：固脉丹辅助筑基；霜魄水、炎髓液用于结丹准备；三轮归元功以散功重修和时间换取法力精纯及更高结丹机会；九旋灵参与配方辅助凝婴；炼虚涉及五行合一；高阶还受天劫和心魔劫制约。

突破失败不统一处理：

- 轻失败：消耗时间与部分材料，积累突破认知。
- 中失败：经脉伤、元气亏损、心境裂隙，需要疗伤或入世历练。
- 重失败：境界跌落、神魂损伤、天劫伤、关键材料尽失，只在高风险路径或明确剧情中使用。
- 正史关键人物死亡与重大突破仍由审核后的剧情矩阵控制，运行时随机数不得改写主干事实。

## 4. 人物属性模型

### 4.1 核心属性

| 属性 | 正文依据与作用 | Unity 表达 |
|---|---|---|
| 境界/小境界 | 决定法力质变、寿元、社会威慑和可用法宝层级 | `realmId`, `realmStage`, `cultivationAccumulation` |
| 灵根与体质 | 决定感应、修炼效率和功法兼容 | 属性数组，不压成单个“资质值” |
| 寿元/年龄 | 闭关与风险的长期成本 | `ageDays`, `lifespanEstimate`, `tribulationClock` |
| 法力 | 施法、驱器、防御、飞遁的主要消耗 | 当前值、上限、纯度、回复率 |
| 神识/神念 | 侦察、锁定、并行操控法宝、傀儡和灵虫 | 范围、精度、控制容量、稳定度 |
| 肉身 | 负伤承受、炼体近战、环境抵抗 | 强度、韧性、恢复、经脉负荷 |
| 元气/精血 | 爆发秘术、重伤和寿元相关资源 | 不等同生命值；使用后长期恢复 |
| 神魂完整度 | 夺舍、魂术、器灵、分神和心魔风险 | `soulIntegrity`, `soulWounds` |
| 遁速/机动 | 追击、脱离、换位，不等于普通移动速度 | 持续遁速、爆发遁速、转向、遁术标签 |
| 心境稳定 | 瓶颈、传承、心魔与重大选择 | 稳定度、执念、人情未结、心魔标记 |
| 控制负荷 | 同时驱使飞剑、法宝、傀儡、灵虫的神识压力 | 使用量/容量；超载增加失控与反噬 |
| 底牌暴露 | 对手是否识别功法、法宝、秘密和撤退手段 | 战斗外持久状态 `exposureLedger` |

### 4.2 抗性不是一排永久百分比

`CANON` 中克制来自功法、材料、法宝、种族、环境和准备。游戏保存以下伤害/控制向量：物理、金木水火土、雷、冰寒、毒、尸煞/魔气、神魂、幻术/心神、空间和法则。

`ADAPTATION-BRIDGE`：每项抗性由临时来源合成：

```text
当前抗性 = 肉身/种族基底 + 功法状态 + 装备/护罩 + 丹药/符箓
         + 环境修正 - 伤势/克制/被破法状态
```

不设置永久“全元素抗性+5%”式垃圾装备。噬金虫的水火不浸、摄魄兽对魂鬼的克制、镇秽玄雷对邪秽的特殊效果，应采用标签和克制规则，而不是简单加总攻击力。

### 4.3 伤势层

1. **肉身伤**：出血、骨伤、脏腑伤、断肢；影响行动与施法姿态。
2. **经脉伤**：降低法力流转和爆发上限，强行施法会恶化。
3. **法力枯竭**：不是受伤，但会失去护体、飞遁和撤退能力。
4. **元气/精血亏损**：强力逃生或禁术代价，按月/年恢复，可损寿元。
5. **神识伤**：降低侦察与控制容量；严重时癫狂、心魔反噬。
6. **神魂伤**：影响夺舍抵抗、器灵/分神稳定和复原，属于高危。
7. **本命法宝反噬**：本命法宝受损会反馈主人；普通装备损坏不套用。
8. **毒、咒、煞与心魔标记**：需要对应解法，不由通用治疗药一键清除。

## 5. 功法、神通与资产分类

### 5.1 功法

| 分类 | 定义 | 正文代表例 |
|---|---|---|
| 主修功法 | 生成并精炼法力，绑定属性路线和境界上限 | 常青养元功、苍元剑典、玄女返生经 |
| 辅助功法 | 改造修炼过程或突破路线 | 三轮归元功（散功重修、压缩真元） |
| 炼神功法 | 提高神识范围、精度与控制能力 | 太衍神念诀 |
| 炼体功法 | 强化肉身、经脉和近身承受 | 不动明身诀、梵魔铸圣功中的炼体路线 |
| 法体双修 | 同时维护法力与肉身路线，前期战力强但时间资源压力大 | 梵魔铸圣功相关路线 |
| 专门传承 | 制符、炼丹、炼器、阵法、傀儡、养虫等知识树 | 附灵符法、傀儡机关术、碧竹流云剑炼制页 |

功法不能只用稀有度表示。每部功法至少记录：属性、层数/篇章、完整度、境界上限、修炼前置、冲突功法、散功风险、传授权、所需时间和来源锚点。

### 5.2 法术、秘术与神通

- **基础/五行法术**：火球、冰箭、御风、护罩等，可直接施放或封入符箓。
- **辅助法术**：天眼术、藏息术、隐匿术；构成侦察和反侦察链。
- **遁术**：御器飞行、土遁、雷遁、赤影遁法。爆发遁术通常消耗法力、精血或专门媒介。
- **功法衍生神通**：苍元剑芒、剑影流光、太庚裂剑阵；必须依赖功法层级和对应飞剑。
- **材料/法宝赋能**：玄雷竹所带镇秽玄雷、霆风翼支持雷遁；能力不能脱离载体永久学会。
- **密术/禁术**：附灵符、分神、身外化身等；高收益伴随精魄、神识或材料风险。

`GAME-ORIGINAL` 的“熟练度”只描述玩家对已获得能力的掌握，不允许把未获得口诀的神通靠重复按键练出来。

### 5.3 法器、法宝与更高宝物

| 类别 | 正文规则 | 代表例 |
|---|---|---|
| 法器 | 常见于炼气/筑基；正文存在下、中、上、顶阶；可成套操控 | 金蜉连环刃、青凝镜 |
| 符宝 | 把法宝部分威能封入符箓，次数/灵力有限 | 灵锋符宝、镇岳塔符宝 |
| 法宝 | 结丹后成为核心；可收入体内、祭炼和长期培炼 | 赤鸾焰环、碧竹流云剑 |
| 本命法宝 | 与主人心神联系深、可持续成长；损坏会反噬 | 七十二口碧竹流云剑 |
| 遗宝/太古遗宝 | 古修士法宝，往往神通单一而威力大；通常不能收入体内 | 空冥殿诸遗宝 |
| 摹制灵宝 | 模仿灵宝能力，威能与门槛均低于正体 | 七曜炎扇等仿制体系 |
| 贯界灵宝 | 需对应御天宝诀等条件驱使/封印培炼；七曜灵陆还以太初万灵录严格区分 | 空冥天鼎、玄风旗、八灵尺（正文语境需逐件复核） |
| 太玄界宝 | 触及天地法则、位于更高层级，不是普通炼器随机产物 | 玄穹断灵剑 |
| 未明特殊物 | 身份尚未揭示时保持未知，不提前把剧情谜底写进 UI | 翠纹灵瓶/掌天瓶的早期状态 |

装备系统不采用固定“头盔、胸甲、鞋、戒指”刷词条框架。角色配置槽以功能为主：本命法宝、主攻法器、护身器、遁器、储物、身份伪装、符箓匣、阵具、驭兽囊和任务物。穿戴式法衣、甲胄、靴、面具仍是具体物品，不是强制套装部位。

### 5.4 符箓、阵法与傀儡

- **符箓**：将一次法术或密术预先制作，换取战斗中的快速释放；材料、绘制成功率、剩余灵力和环境决定效果。代表：地行符、火鸟符、太清匿形符、六甲玄罡符、附灵符。
- **阵法**：由阵旗、阵盘、地形、灵气与布置时间共同构成。代表：逆转五元阵、五元乱迹阵、微尘须弥刚阵、隐匿阵法。剑阵单列为功法+本命飞剑的战斗结构。
- **傀儡**：独立于灵兽，消耗材料、灵石/灵力和神识控制；机关兽有等级，上阶人形机傀具有专门功能。损坏应留下可修复部件而非自动复活。

### 5.5 丹药、灵药和炼制材料

分类按用途而非颜色稀有度：

- 修为丹：加快特定境界的修为沉淀，但境界过高后药效有限。
- 突破丹/辅材：固脉丹、九旋参元丹路线、霜魄水、炎髓液。
- 恢复丹：恢复法力或元气，具有服用时间和吸收速度，不能瞬间灌满所有资源。
- 疗伤/解毒：针对肉身、经脉、毒、煞；不可治疗不匹配的神识伤。
- 功能丹：驻容丹等非战力效果。
- 灵药：霞衣草、九旋灵参及各配方药材；记录年份、成熟阶段、保存和来源。
- 妖丹、精魄、灵木、矿材：同时用于炼器、制符、养兽和功法前置，形成用途冲突。

翠纹灵瓶是隐秘生产能力：它加速药草年份形成，不直接生成丹药，也不补齐丹方、辅材、地火、炼丹技术和失败风险。

### 5.6 灵兽、灵虫与器灵

| 类别 | 代表 | 关键规则 |
|---|---|---|
| 灵兽/奇兽 | 摄魄兽、斑麟兽 | 有物种、等阶、天赋、忠诚/契约与自主行为 |
| 灵虫 | 噬金虫、血晶蛛群、六翎寒蜈 | 群体数量、成熟阶段、互克、饲育环境与操控负荷 |
| 器灵 | 月珞 | 依附器物但可能有记忆、意志和身份；不是“宠物品质” |
| 傀儡 | 机关兽、人形傀儡 | 制造物，走维修、供能和神识控制体系，不进入宠物繁殖 |

器灵过度化形或强制驱使可能损耗精元乃至溃散。月珞一类有自我意识的器灵使用关系、同意和秘密状态，不使用“喂食提升忠诚度”的宠物模板。

## 6. 战斗系统

### 6.1 适配影视互动的战斗形态

本项目不是自由镜头动作游戏。战斗采用**数据先结算、影视后表现**的策略节点：

```text
战前配置 -> 侦察与站位 -> 第一轮试探 -> 底牌/阵法升级
         -> 胜、撤、拖延、救援或任务达成 -> 战后持续状态
```

每个决策节点给出 2–4 个固定选项并可接受受控语音意图。Unity 根据锁定的规则和种子先产出 `CombatResolution`，再播放对应的 4–8 秒预生成镜头；AI 视频不能自行决定谁胜谁负、掉落什么或角色是否死亡。

### 6.2 战斗资源

- **法力**：施法、护体、驱器、飞遁。低于安全储备后，撤退选项会减少。
- **神识控制负荷**：侦察、锁定、同时驱使飞剑/傀儡/虫群。超载造成延迟、目标丢失或神识伤。
- **肉身状态**：姿态、伤势、经脉承载和环境承受。
- **元气/精血**：禁术与强行脱身的长期代价，不按回合自然回满。
- **神魂/心境**：魂术、幻境、夺舍和心魔相关。
- **消耗品与宝物状态**：符箓次数、丹药、阵旗完整度、法宝灵性、本命联系。
- **环境灵气**：影响恢复、阵法、六甲玄罡符等借天地灵气的能力。
- **时间与撤退窗口**：秘境闭合、援军、追兵、队伍伤员和阵法启动倒计时。
- **底牌暴露度**：使用稀有能力会提高敌对势力识别、追踪和后续针对概率。

### 6.3 战前准备

玩家必须在容量和风险之间选择：

1. 整理情报：敌方已知境界、功法属性、法宝、同伴、地形与不确定项。
2. 设定目标：击杀不是默认目标，可选采药、救人、拖延、夺物、过关或撤离。
3. 配置载荷：法宝/法器、护身器、遁术媒介、符箓、丹药、阵具、傀儡、灵兽/灵虫。
4. 安排退路：安全点、土遁/雷遁条件、接应者、弃物诱敌方案。
5. 决定公开信息：用低阶手段隐藏真实修为，还是先以境界威慑避免战斗。

错误配装不必直接判负，但会改变可用选择。例如没有准备遁符仍可徒步撤退，只是更慢、更易被追上；没有对魂手段时，啼魂类敌情会迫使玩家绕行或谈判。

### 6.4 侦察与反侦察

侦察渠道：肉眼/听觉、神识、天眼/灵目、灵虫、傀儡、阵法反馈、NPC 情报和环境痕迹。

正文显示神识会被禁制阻挡，也可能因主动探查而被强者察觉。系统因此使用三项结果：

- `informationGained`：识别到的实体、境界区间、阵眼或异常。
- `confidence`：确定、可信、可疑、未知；UI 不把猜测显示成事实。
- `counterDetection`：自身位置、神识特征或功法是否被对方捕捉。

藏息术可对抗天眼术，但不是对所有高阶神识永久隐身；禁制阻断神识也可能反过来提示“此处有东西被隐藏”。

### 6.5 法力、神识与法宝操控

- 一个法宝动作同时消耗法力与神识控制量；成套飞剑的控制成本由功法、凝神术和本命联系修正。
- 高控制负荷下继续增开傀儡/虫群，会降低精度和反应而非简单禁止。
- 本命法宝更顺手且可长期成长，但被毁伤会反噬；遗宝威力大却需携带、不能按普通本命宝收入体内。
- 贯界灵宝必须检查对应御天宝诀、封印/炼化状态和驱动条件，捡到不等于立刻装备。
- 法宝自爆、精血遁术、分神等只出现在“接受长期代价”的高风险选项，不做常规最优循环。

### 6.6 阵法与区域控制

阵法状态包括阵眼、阵旗/阵盘、供能、覆盖区域、隐蔽度、已识别规则和完整度。玩家可以：

- 预先布阵、诱敌入阵、用相克属性破阵；
- 以神识/灵目寻找阵眼，但承担反侦察风险；
- 强攻阵壁，付出法力、时间和援军到达风险；
- 夺取或破坏局部阵旗形成撤退缺口；
- 放弃阵具快速撤离，永久损失部分材料。

阵法不能作为背包中即时展开的“范围技能”，除非该阵具正文上明确允许快速布置。

### 6.7 撤退、失败和任务胜利

撤退是主动作战目标。一次“战斗胜利”可以是：带药撤离、救出伤员、拖到禁制开启、保住秘密、确认情报或逼退敌人。

撤退检查考虑：双方爆发遁速、持续法力、追踪手段、环境、预设出口、伤员、诱饵与是否暴露高阶遁术。成功撤退仍结算时间、伤势、丢弃物和敌人认知。

死亡只用于玩家主动接受的致命风险、关键正史或撤退资源全部耗尽后的明确结果。普通失败优先进入：被迫交物、队友受伤、秘境目标丢失、身份暴露、宗门处分、被追踪或换地图逃亡。

### 6.8 战后结算

战后不发放角色 XP，结算以下可追溯对象：

```text
存活/任务状态
伤势、法力、元气、神识和法宝损伤
世界时间推进
消耗与遗失的实物
获得的材料、丹方、口诀残页、法宝、情报
关系、人情债、宗门义务与仇怨
底牌暴露与敌方适应记录
地点资源枯竭、尸体/痕迹和后续追兵
```

夺得物品还要经过鉴定、检查旧主印记/追踪、兼容性判断、炼化或交付任务，不能在结算画面直接变成无风险战力。

## 7. 学习、提升与获得资产

### 7.1 学习功法

取得途径：

1. 师门传功、拜师与宗门藏经权限。
2. 师父抄本、玉简、玄金残页、骨片和残缺口诀。
3. 剧情托付或交换，例如传承送还任务。
4. 遗迹机关、法宝内附御天宝诀、器灵/前辈讲解。
5. 战利品或夺宝，但伴随残缺、禁制、追踪、誓约和阵营报复。
6. `ADAPTATION-BRIDGE` 的女性线宗门课程与长老指导，只能补写原著留白，不凭空创造越阶神通。

学习检查包括：文本完整度、识字/神识读取能力、灵根与体质、前置功法、师承许可、领悟、时间和心境。只“拥有玉简”不等于已学会。

### 7.2 功法层级和熟练

每部功法优先使用自己的正文层数。例如常青养元功/炼气口诀到十三层，苍元剑典有其篇章，太衍神念诀有自身层级。只有正文没有统一称法时，才用 `GAME-ORIGINAL` 的五档表现层：初识、入门、熟练、精通、圆满。

提升来源：

- 闭关运转与真实世界时间；
- 老师纠错、玉简注解和完整后篇；
- 在合适灵脉、地火、极寒等环境参悟；
- 实战验证只能提升施用熟练和情报，不能凭空增加主修修为；
- 心境磨炼或入世经历用于正文要求的关口；
- 丹药加快修为积累，但不能替代口诀理解和境界瓶颈。

### 7.3 剧情传承与随机机缘

随机机缘不是“每次开箱随机出神功”。系统从人工审核的 `OpportunityDefinition` 中抽取，条件由地点、时代、人物关系、已知情报、世界时钟和唯一性共同决定。

机缘结构：线索 → 选择投入 → 风险 → 可错过窗口 → 结果。结果可能是残页、材料、师承、人情或敌人，并非必定获得宝物。翠纹灵瓶、玄金残页、空冥殿、九旋灵参等仅作为结构参考，正史唯一物不得复制刷取。

### 7.4 炼丹、炼器和制符

统一制作输入：配方完整度、材料种类/年份/品质、火源与器具、制作者知识、法力/神识、时间和场所安全。

失败可产生：材料全部损失、次品、效力下降、毒性、灵性损伤、炼制者受伤或暴露异象。九旋参元丹的稀缺材料说明高阶失败必须真实有代价。

炼器额外检查材料相容、阵纹、成套一致性、丹火/地火和祭炼时间。本命法宝制成只是起点，还需多年培炼。制符以预付材料和制作时间换取战斗中的快速释放。

### 7.5 法宝鉴定、认主和炼化

```text
取得实物 -> 隔离与鉴定 -> 检查旧主神识/精血/禁制/器灵
         -> 清除或谈判 -> 功法与境界兼容 -> 祭炼
         -> 装备/收入体内/封印培炼 -> 长期维护
```

初阶纳物囊正文明确没有认主保护；其他物品逐件定义。不能用一条“滴血认主”规则覆盖所有法宝。贯界灵宝要额外满足御天宝诀，遗宝不能按普通法宝收入体内，有自主意识的器灵需要关系和意志处理。

### 7.6 灵兽、灵虫与器灵培养

- 来源：卵、幼体、捕获、交换、任务托付、器物唤醒；每个物种有合法来源表。
- 绑定：控神仪式、灵兽契约、器物依附或关系协定，不能统一成宠物球。
- 成长：年龄/成熟阶段、妖丹和特定饲料、灵气环境、训练时间、群体规模和血脉条件。
- 能力：物种天赋优先；啼魂的魂鬼克制、噬金虫的群体吞噬和材料抗性不能随机换技能。
- 风险：死亡、逃逸、反噬、精元损耗、虫群失控、器灵溃散；高阶伙伴不是无损召唤物。

## 8. 男女双主线落地

### 8.1 沈砚线

早期循环：常青养元功与翠纹灵瓶秘密 → 采药/炼丹 → 练气层级与筑基准备 → 敛气、法器、符箓和撤退。  
中期循环：苍元剑典/太衍神念诀 → 三轮归元功与时间代价 → 碧竹流云剑、本命培炼、阵法、傀儡和虫群控制。  
后期循环：法体双修、多宝协同、剑阵、灵宝与界面规则，但仍保留天劫、神识负荷、秘密暴露和世界时间成本。

沈砚的特殊优势是资源生产与长期准备，不是战斗掉落倍增。翠纹灵瓶秘密一旦暴露，应触发势力级追索而非普通仇恨值。

### 8.2 楚明绮线

- `CANON`：玄女返生经会周期性轮回法力与外观状态；赤鸾焰环是核心法宝。
- `ADAPTATION-BRIDGE`：把轮回表示为 `cultivationStateModifier`，角色真实境界、社会身份、当前可调用法力和暴露风险分别保存。它不是删除等级再练一次。
- 宗门资源可提供阵法、符箓、弟子协作和情报，但同时产生宗门义务、伤亡责任与政治可见度。
- 主要战斗目标更常是掩护门人、控制区域、隐藏真实修为和选择何时暴露赤鸾焰环，而不是复制沈砚的夺宝/养虫循环。

### 8.3 苏绛璃与月珞接力

苏绛璃接力可使用组织、海上情报、啼魂相关剧情与身份风险；月珞接力聚焦器灵形态、记忆、依附器物和自主选择。二者使用同一 `CombatantState`，但不得被强制套入完整主角境界养成树。

## 9. 数值原则、反刷取和失败继续

### 9.1 数值原则（`GAME-ORIGINAL`）

1. 境界用离散 `realmRank`，同境界细节用 0–100 的局部量表；不制造百万攻击力。
2. 先比较境界权限/压制，再比较法力纯度、神识、功法、克制、装备和准备。
3. 概率对玩家显示“极低/低/可行/较高/稳妥”及影响因素，不伪装成正文不存在的精确百分比。
4. 受控随机数必须可复现：`storySeed + encounterId + attemptIndex`；读档不能无成本洗结果。
5. 恢复丹药有吸收时间和同类递减；境界不匹配的低阶药效果衰减。
6. 稀有度描述世界稀缺性，不自动决定战斗强度；相克和适配可能让普通道具成为正确答案。
7. “幸运”不做可堆叠基础属性。机缘由条件、信息、关系、路线和受控随机共同决定。

### 9.2 反刷取

- 敌人、药草、遗迹和宝物属于世界实体，不在原地无限刷新。
- 重复猎取会降低地区生态资源、提高妖兽警觉、宗门关注和坊市价格波动。
- 同类低阶战斗只提供已知材料和微量施用熟练，不能增加境界修为。
- 唯一传承和正史宝物拥有全局唯一 ID；复制品必须是单独的审核内容。
- 重新读档使用同一事件种子；重大机缘的结果在进入事件时锁定。
- 敌对势力记录已暴露底牌并准备克制，重复使用同一套路边际收益下降。
- 炼制、闭关、养虫和疗伤消耗世界时间，不能靠菜单操作跳过所有外部后果。

### 9.3 失败继续

建议失败阶梯：

| 等级 | 后果 | 继续方式 |
|---|---|---|
| 可控撤离 | 消耗符箓、法力、时间，任务次目标失败 | 回安全点、换路线 |
| 代价失败 | 丢物、负伤、队友撤离或关系下降 | 疗伤、还债、补救任务 |
| 战略失败 | 秘境关闭、宗门败退、身份暴露 | 换地图/身份，进入新的主线状态 |
| 致命失败 | 仅在明确警告和无撤退资源时 | 正史锁定或重新从章节检查点开始 |

章节检查点恢复不能回滚在线服务、外部生成或未锁定内容；所有关键结果都要有预生成备用镜头。

## 10. Unity 数据化

### 10.1 运行时对象

- `CultivationState`：境界、阶段、修为沉淀、灵根、瓶颈、天劫和寿元。
- `CombatantState`：法力、神识、肉身、元气、神魂、伤势、抗性和暴露。
- `TechniqueDefinition/State`：功法规则与角色掌握状态分离。
- `AssetDefinition/AssetInstance`：同一种物品定义与具体耐久、旧主印记、器灵状态分离。
- `CompanionState`：灵兽、灵虫群、器灵、傀儡分别使用子类型。
- `EncounterDefinition`：审核锁定的敌人、地形、目标、方案矩阵和可播放媒体。
- `CombatResolution`：确定性状态变化、镜头 ID、备用镜头和审计信息。

### 10.3 结算顺序

```text
验证剧情与角色状态
-> 锁定随机种子
-> 生成双方可见/隐藏情报
-> 检查方案前置、资源和撤退储备
-> 解析克制、境界压制、阵法和控制负荷
-> 写入原子 StateEffect
-> 选择主镜头与离线备用镜头
-> 记录审计日志、来源版本和内容哈希
```

运行时大模型只能把玩家语音归入已审核的战斗意图，如“隐藏”“试探”“护送”“强攻阵眼”“撤退”；它不能创建新功法、改写宝物能力或擅自决定正史人物死亡。

## 11. 首个垂直切片建议

赤雾秘苑只实现以下最小闭环：

1. 沈砚/楚明绮两个入口，共享世界事实和墨蛟战场。
2. 炼气一至十三层、楚明绮真实境界与轮回状态的双层表达。
3. 法力、神识、伤势、底牌暴露和撤退储备五组核心状态。
4. 金蜉连环刃、符箓、赤鸾焰环、阵法/禁制、墨蛟材料五类内容。
5. 侦察、试探、限制、协作、撤退五种意图；不先实现完整 2446 章装备库。
6. 战后以资源、伤势、秘密、关系和世界时间结算，不发 XP。

验收时必须验证：同一战斗种子结果可复现；法力耗尽会真实关闭选项；撤退可以成为有效结局；楚明绮不是沈砚换皮；任何视频生成失败都有一致的备用镜头；所有能力都能追溯到正文锚点或清楚标记为游戏原创。
